# FastAnim — unofficial Fabric 1.21.1 port

This is a community compatibility port of FastAnim by Lunade for Minecraft 1.21.1 on Fabric. It keeps the original faster_entity_animations mod ID so a launcher prevents loading the original and port together.

The published FastAnim JAR identifies the project as MIT and includes the copyright notice for Lunade Music. That notice is preserved in LICENSE. The upstream Modrinth project has no source repository link, so this port was reconstructed from the published 1.20.1 JAR and mapped against Yarn 1.21.1.

This work is unofficial and is not endorsed by the original author. Report compatibility issues to this port's maintainer.

The `tools/map_intermediary_sources.py` helper converts intermediary Minecraft identifiers in Java sources using the Yarn mappings archive. It is a development aid and is not required to build the port.

This port and its compatibility documentation were prepared with AI assistance.
